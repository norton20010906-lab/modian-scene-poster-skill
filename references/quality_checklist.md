# 最终质量检查表

## 自动项

- [ ] `verify_output.py` 返回 `valid: true`
- [ ] PNG 为 1080×1350、RGB
- [ ] 品牌严格为“魔点门禁”
- [ ] 型号与资料库标准型号一致
- [ ] 卖点为 3～4 条且 ID 全部存在于资料库
- [ ] `layout.text_overflow` 为 `false`

## 人工视觉项

- [ ] 产品仍能被识别为输入设备
- [ ] 轮廓、屏幕比例、摄像头位置和主色没有明显漂移
- [ ] 产品安装比例、透视、接触阴影合理
- [ ] 场景属于资料库允许的使用场景
- [ ] 标题在缩略图下仍清晰可读
- [ ] 没有乱码、伪 Logo、水印、悬浮设备或畸形人物
- [ ] 文字区与产品主体没有冲突

任一关键项失败即不交付。产品结构漂移、卖点不可信和文字乱码属于关键失败；轻微背景差异不属于关键失败。
