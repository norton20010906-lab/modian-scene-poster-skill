# 最终质量检查表

## 自动项

- [ ] `verify_output.py` 返回 `valid: true`
- [ ] PNG 为 1080×1350、RGB
- [ ] 品牌严格为“魔点门禁”
- [ ] 型号与资料库标准型号一致
- [ ] 卖点为 3～4 条且 ID 全部存在于资料库
- [ ] `layout.text_overflow` 为 `false`
- [ ] 场景产品框宽度至少占画面 18%
- [ ] 使用状态标签时，`layout.status_badge_drawn` 为 `true`

## 人工视觉项

- [ ] 产品仍能被识别为输入设备
- [ ] 轮廓、屏幕比例、摄像头位置和主色没有明显漂移
- [ ] 产品安装比例、透视、接触阴影合理
- [ ] 产品是画面主角之一，缩略查看仍能辨认屏幕、传感器和边框
- [ ] 人物的脸部或头部明确朝向设备，形成刷脸动作关系
- [ ] 真实存在的产品 Logo 得到保留；原图无清晰 Logo 时没有虚构 Logo
- [ ] 状态标签位于产品附近且不遮挡产品关键细节
- [ ] 场景属于资料库允许的使用场景
- [ ] 标题在缩略图下仍清晰可读
- [ ] 没有乱码、伪 Logo、水印、悬浮设备或畸形人物
- [ ] 文字区与产品主体没有冲突

## 四候选检查

- [ ] P1～P4 都是独立的 1080×1350 成品，不是同一版式只换颜色
- [ ] 四张候选共享同一组已验证卖点，没有因模板变化新增功能
- [ ] 四宫格编号不遮挡品牌、型号、标题、产品或卖点
- [ ] `candidate_manifest.json` 的编号、模板 ID 和文件路径一一对应
- [ ] 用户选择前状态为 `awaiting_user_selection`，四宫格不冒充最终单张海报

任一关键项失败即不交付。产品结构漂移、卖点不可信和文字乱码属于关键失败；轻微背景差异不属于关键失败。
