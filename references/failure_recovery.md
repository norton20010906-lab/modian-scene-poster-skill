# 失败恢复

| 失败 | 处理 | 是否继续 |
|---|---|---|
| 图片不存在或格式不支持 | 请求 PNG/JPG/JPEG/WebP | 否 |
| 商品截图无法分离主体 | 请求单独产品图或更清晰截图 | 否 |
| 型号未收录 | 告知 V1 仅支持内置型号 | 否 |
| 型号处于禁用状态 | 列出待补资料，不推断功能 | 否 |
| 已验证卖点少于 3 条 | 请求补充可信资料 | 否 |
| 内置图像工具不可用 | 保留 JSON，说明无法完成主视觉 | 否 |
| 第一次产品外观漂移 | 只针对漂移锚点编辑一次 | 是 |
| 第二次仍漂移 | 使用原图产品裁切合成，记录回退 | 是 |
| 文案超长 | 缩短标题/副标题，再次校验 | 是 |
| 卖点或禁用表述校验失败 | 只从资料库重新选择，不改资料库 | 是 |

## 裁切合成回退

回退的目标是保住产品真实性，不追求完美的安装融合。使用输入图中真实产品区域，移除商品页 UI，保持原始比例，放入预留安装区，添加克制的接触阴影。若无法获得干净边缘，不伪造透明抠图，直接请求更清晰产品图。

不要因为内置图像工具失败而自动切换到 CLI、外部 API 或联网服务。
