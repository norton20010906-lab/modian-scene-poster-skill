# 内部版式库与四候选选择流程

版式库服务于 Agent 决策，不是面向用户的风格商城。用户不需要理解或预选模板；Skill 在掌握产品、卖点与场景后选择合适模板，并先输出四张候选供结果级选择。

## 当前默认模板

- `editorial-feature-grid`（P1）：黑底大标题、三列平铺功能、底部宽幅场景。适合三个并列卖点。
- `centered-story-window`（P2）：居中双层标题、简短说明、底部场景窗口。适合一句核心主张和企业入口叙事。
- `product-closeup-overlay`（P3）：设备极近景、屏幕识别反馈、人物叠影。适合强调硬件外观和识别动作。
- `asymmetric-campaign-hero`（P4）：不对称标题、产品大比例主视觉、纵向卖点。适合高端品牌和产品质感表达。

## 生成原则

1. 四张候选共享同一份已验证文案与卖点 ID，模板不得新增功能事实。
2. 兼容模板可以复用同一场景图；不同构图需求必须生成独立主视觉。
3. 每张候选均为 1080×1350；四宫格只用于比较，不能当作最终海报。
4. 四宫格按 P1、P2、P3、P4 排列，并生成可追溯清单。
5. 用户只在四宫格完成后选择编号；选择后展示对应全尺寸文件。

## 新模板进入积累库的门槛

- 有可描述的商业排版规律，不是对单张作品的像素级复刻。
- 明确 `best_for`、主视觉类型和产品占比目标。
- 中文完全由本地排版生成。
- 至少完成一个真实产品样例和一次缩略图可读性检查。
- 不与现有模板只做颜色或微小位置差异。
- 通过模板注册表校验、尺寸检查、文本溢出检查和人工视觉复核。

## 选择后的行为

用户回复 P1～P4 后：

1. 从 `candidate_manifest.json` 精确定位模板和文件。
2. 展示对应的单张 1080×1350 海报。
3. 若用户提出修改，只迭代该模板一次；不要无条件重跑四张。
4. 最终清单记录 `selection_status: selected`、选择编号和最终文件。
