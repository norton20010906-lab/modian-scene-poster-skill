# 运行工作流

## 运行目录

每次调用创建独立目录 `output/YYYYMMDDTHHMMSSZ/`。不要覆盖旧文件。先保存结构化文件，再进行不可确定的图像生成，以便失败后恢复。

## 阶段与产物

1. 输入校验：标准化图片路径、型号和补充要求。
2. 资料匹配：读取一个启用且来源已验证的产品记录。
3. 视觉分析：写入 `analysis.json`。
4. 场景规划：写入 `scene_plan.json`。
5. 内容草稿：写入 `copy.json`。
6. 内容校验：输出 `copy.validated.json`。
7. 主视觉生成：保存 `scene.png`。
8. 确定性排版：输出 `poster.png` 和 `manifest.json`。
9. 自动与人工验收：成功后交付绝对路径。

结构化 JSON 文件统一使用 UTF-8、两空格缩进和中文原文，不使用转义后的中文。

## 状态原则

- 前置资料错误：不创建场景图。
- 图像生成失败：保留分析、场景和文案文件。
- 排版失败：保留场景图，修正文案后重试。
- 验收失败：不要把 `manifest.status` 手工改为 `complete`。
